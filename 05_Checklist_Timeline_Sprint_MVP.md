# 📆 Timeline Pengembangan MVP Tagihanku

> Durasi estimasi: **6 Minggu** (Agile-based Development)

---

## ✅ Tabel Timeline Pengembangan

| Minggu | Tahapan | Output / Deliverable |
|:------:|---------|--------------------|
| **1** | Perencanaan & Desain | - Finalisasi fitur MVP<br>- PRD, SRS, ERD, SDD<br>- Wireframe UI Tagihanku<br>- Rencana Sprint |
| **2** | Setup Proyek & Arsitektur | - Setup Flutter project<br>- Struktur Clean Architecture<br>- Dependency setup (Riverpod, GoRouter, Drift, Freezed)<br>- Routing & Theme dasar |
| **3** | Pengembangan Fitur Tagihan | - CRUD Tagihan (Bills)<br>- HomeScreen + Add/Edit Bill UI<br>- Riverpod untuk state & data<br>- Local persistence awal |
| **4** | Fitur Kategori & Kalender | - Assign kategori ke tagihan<br>- Halaman pengelolaan kategori<br>- Tampilan kalender dasar<br>- Indikator tanggal jatuh tempo di kalender |
| **5** | Reminder & Pengaturan | - Local notification scheduler<br>- UI & logic untuk mengatur pengingat tagihan<br>- Halaman Pengaturan (Theme + Notifikasi) |
| **6** | Testing, Debugging & Rilis MVP | - Unit test & integration test<br>- Perbaikan bug<br>- Build APK<br>- Internal Alpha Release |

---

## 🎯 Target MVP

✔ CRUD Tagihan  
✔ Kategori Tagihan  
✔ Kalender Dasar  
✔ Reminder/Notifikasi  
✔ Light & Dark Mode  
✔ Offline-first (Drift)

🚫 **Tidak termasuk dalam MVP awal:**
- Sistem Login/Akun Pengguna
- Sinkronisasi ke cloud
- Fitur PRO seperti laporan bulanan & tagihan berulang

---

## 🔄 Sprint Breakdown (Agile)

| Sprint | Durasi | Fokus | Output |
|-------|--------|------|--------|
| Sprint 1 | Week 1–2 | Dokumentasi & Setup | Dokumen final + Struktur project siap pakai |
| Sprint 2 | Week 3 | Core MVP Bills Feature | CRUD Tagihan berfungsi penuh |
| Sprint 3 | Week 4–5 | Category + Calendar + Reminder | Fitur pendukung utama lengkap |
| Sprint 4 | Week 6 | Pengujian + Rilis Internal | APK siap untuk demo & evaluasi |

## ✅ Indikator Keberhasilan MVP

| Metrik | Target |
|---|---|
| Semua fitur MVP berjalan | 100% ✅ |
| Persistensi data | Data tagihan tidak hilang setelah aplikasi ditutup ✅ |

| Feedback pengguna | Diterima untuk iterasi pengembangan selanjutnya |

## ✨ Kesimpulan
Timeline ini dirancang untuk menyelesaikan aplikasi **Tagihanku** dari tahap **desain → implementasi → testing → hingga rilis MVP** dalam waktu **6 minggu**, dengan menggunakan pendekatan agile untuk peningkatan berkelanjutan.
